# Телефонный справочник

Домашнее задание по курсу Python разработчик.

Справочник на классах с разделением на MVC. Контакты хранятся в contacts.json.
Перед работой нужно открыть файл через пункт 1. Изменения сохраняются через
пункт 2 или при выходе из программы.

## Запуск

```bash
python3 phonebook.py
```

## Тесты

Тесты находятся в testing/test_phonebook.py.
Проверяются добавление, поиск, изменение, удаление контактов, открытие и
сохранение файла. Есть проверки неверных данных и исключений.

Установка pytest и запуск из папки проекта:

```bash
python3 -m pip install pytest
python3 -m pytest -v
```

Команду установки выполнять в своём виртуальном окружении.
Для тестов используется отдельный testing/test_contacts.json.
Рабочий файл contacts.json тесты не меняют.
