# Телефонный справочник

Рефакторинг домашнего задания по курсу Python разработчик.

## Запуск

```bash
python3 phonebook.py
```

Файл `contacts.json` лежит рядом с `phonebook.py`. Перед работой нужно выбрать
пункт 1, чтобы открыть его. Изменения сначала остаются в памяти, а пункт 2
сохраняет их в файл. При выходе программа предлагает сохранить изменения.

## Структура

- `phonebook.py` — запуск программы и путь к файлу.
- `view.py` — меню, ввод и вывод контактов.
- `controller.py` — действия по пунктам меню.
- `model.py` — классы контакта, справочника, чтения и записи файла; здесь же
  находятся свои исключения для ошибок файла и контактов.
- `contacts.json` — контакты.

Поиск выполняется по имени, телефону и комментарию. Для изменения или удаления
сначала ищем контакт, затем выбираем его ID из найденного списка.
